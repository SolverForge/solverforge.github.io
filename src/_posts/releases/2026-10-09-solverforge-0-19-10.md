## What Changed

### Optional construction continues past completed decisions

Keeping an optional assignment unassigned completes that decision, not the
whole optional pass. Completed optional roots are excluded before candidate-domain
reads and move generation, so they cannot consume the candidate budget needed by
later rows. Completion recognizes the assignment group slot for a kept-unassigned
root while preserving occupied rows as blockers for required augmenting rematches.
Regression coverage includes both completing a later optional assignment and
retaining access to assigned occupants during required rematching.

### Unary filters run before keyed equality initialization

For the first unary keyed equality cross-join, an accumulated left unary filter
becomes source membership before key extraction and pair creation. Filtered unary
right targets retain their own membership. Nullable rows can therefore be excluded
before a key closure unwraps their assignment value. Original source indexes and
descriptor-local change metadata are preserved, including incremental transitions
into and out of membership. Filters authored after the join operate on joined rows
and do not protect earlier key extraction.

This left-source pushdown applies to the first unary keyed equality cross-join,
not comparison, overlap, composed-condition, predicate, or same-source self-join
dispatch. Its membership adapter is hidden implementation support, not a public
modeling API.

### Documentation states the actual runtime and fluent boundaries

Omitted phases use state-aware construction. One default streaming local-search
phase is eligible only with effective parsed top-level termination. Absent
termination, an empty termination object, or invalid score-only termination leaves
the omitted-phase plan construction-only; VND is not implicitly prepended.

Fluent right-hand targets implement `CollectionExtract`, including filtered unary
streams. Arbitrary compatible derived producers can feed either low-level
`JoinNode` input; they are not interchangeable fluent targets.
`stream::cross::Penta::join` continues into arity-free `Chain`, but currently
discards an authored penta filter: apply the row filter on the returned `Chain`.
Same-source `PentaConstraintStream` is terminal.

Release generation now checks updater round trips and the README replacement
regression, synchronizes workspace documentation, and regenerates the architecture
page after a version bump. These are documentation and release-tooling corrections,
not a new default-search policy or a new fluent-target capability.

### Internal zero-regression qualification is satisfiable and layout-fair

The controlled-host gate checks deterministic `allocations`, `allocated_bytes`,
and `peak_live_bytes` exactly, with no noise allowance or permitted increase.
Noisy wall-time, RSS, and available hardware-counter medians use
`BENCH_TOLERANCE_PERCENT`, a default 5% regression tolerance. The paired bootstrap
95% upper bound remains a diagnostic, not the acceptance criterion.

Both sides use the same harness package name and equal-length staging paths,
avoiding symbol-mangling and embedded-path layout differences between identical
sources. Per-case `.text` SHA-256 fingerprints are recorded. Full-enumeration
candidate count and order are still checked separately from first-fit work.
This corrects internal release qualification; it does not rerun or alter historical
site benchmark measurements, recorded tested versions, or warehouse evidence.

## Upgrade Checklist

- Update direct Rust dependencies and confirm `Cargo.lock` resolves `0.19.10`.
- Test optional rows that deliberately remain unassigned before later assignable
  rows; verify candidate budgets do not disappear into already completed roots.
- Filter nullable unary sources before the first keyed equality cross-join and
  test incremental/full-score parity as rows enter and leave membership.
- Recheck effective termination when relying on omitted-phase local search.
- Move cross-Penta row filters to the returned `Chain`, and keep arbitrary derived
  producer composition at the low-level operator boundary.
- Upgrade CLI-generated apps deliberately: CLI 3.3.3 still scaffolds core 0.19.7;
  this release does not retarget scaffolds, rebuild Python wheels, or update apps.
