## What Changed

### Existence joins are answered from per-key occurrence counts

`ExistenceNode` no longer materializes right-side child rows and pair links. It
keeps one occurrence count per right-side key — dense arrays for `usize`
planning ids, hash tables otherwise — together with the stored key contribution
of each right row and one key bucket of left rows. When a key's count crosses
the alive/dead threshold, the engine publishes or retracts every left row
carrying that key in one idempotent membership pass per event; nothing else
changes. Right-side children never become rows and never receive handles.

### Pair joins stay where the relationship itself needs pairs

`JoinerExistenceNode`, the compiled-plan engine for residual predicates, keeps
joining pair rows. Complements keep their per-pair restore, now through
retained keys (`KeyOf`) instead of stale row handles, which fixes
`complemented_rows_remain_joinable`.

### Incremental notifications use caller-owned buffers

`Operator::retract`/`insert` append into caller-owned `&mut Vec<RowHandle>`
buffers and `RowChanges` is removed: an event costs one memcpy per hop and no
heap allocation on this path. Custom operator code compiled against `RowChanges`
must switch to the caller-owned buffers; ordinary constraint-stream models are
unaffected and expose no new modeling API.

### Upstream validation

Workspace Clippy with `-D warnings` and the full test suite are green. The
upstream parity probe X-n167-k10 reports 2,989 ms median against a 4,349 ms
baseline with parity in score, steps, and evaluated candidates. That is the
upstream probe measurement; it is not a site benchmark result, no
performance claim is made for the published site workload, and historical
benchmark evidence and tested versions remain unchanged.

## Upgrade Checklist

- Update direct Rust dependencies deliberately and validate `Cargo.lock`
  against the current core `0.19.13`.
- Compare incremental and full scores across semi/anti join churn: key
  additions, removals, and re-adds that cross the alive/dead threshold, plus
  residual predicates on `JoinerExistenceNode`.
- Revalidate complemented streams in custom plans; complement restore now goes
  through retained keys rather than stale row handles.
- Port operator code compiled against `RowChanges` to caller-owned
  `&mut Vec<RowHandle>` notification buffers.
- CLI 3.3.3 still scaffolds core 0.19.7. This release does not rebuild Python
  wheels, upgrade apps, retarget scaffolds, or rerun site benchmarks.
